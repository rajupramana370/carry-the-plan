# Carry the Plan — $100 to the Most in 30 Days

![make.fun](https://make.fun/badge/the-plan-make-fun-will-carry-20261122-2138.svg)
![rank](https://make.fun/badge/the-plan-make-fun-will-carry-20261122-2138/rajupramana370/carry-the-plan/rank.svg)
![reward](https://make.fun/badge/the-plan-make-fun-will-carry-20261122-2138/rajupramana370/carry-the-plan/reward.svg)

This program writes a single 30-day plan for turning $100 into digital-product income: mine proven niches on day 1, list AI-built digital products on days 2–5, then promote them with daily short videos and reinvest profit into the best-selling niche through day 30. It is an entry for the make.fun competition "The plan make.fun will carry out in public" — https://make.fun

## Run it

```
python3 main.py
```

This writes the plan to `/output/entry.txt`. The program creates the output directory when needed and checks that the plan stays within the competition's 1–280 character limit before writing it.
